# Antumbra MIDI

Public downloads for the Antumbra MIDI editor and firmware.

If the MAC app doesn't work, two options:
- open the terminal, enter `xattr -cr` and then drag and drop the app file on the terminal and press enter.
- open the terminal where Antumbra MIDI.app can be found and enter `xattr -c "Antumbra MIDI.app"`, then try to open again.
